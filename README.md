# Ecommerce Optitech Store

Este proyecto fue realizado para el 3er curso de la carrera de Programador Full Stack de Coderhouse, y es el curso de **React**.

En este curso vimos desde lo básico, hasta lo más avanzado en esta tecnología. Son 15 clases, 2 por semana, con 4 afterclass (clases en las que se agregaba algun tema particular que no se veía en el curso), donde pudimos ver:

- Una introducción a React, como instalarlo y preparar el entorno.
- Como funciona JSX y el transpiling.
- Los componentes en React.
- Promesas y asincronías.
- Como consumir API's.
- Hooks y patrones.
- Routing y navegación.
- Eventos en React.
- Como crear y consumir contextos.
- Técnicas de rendering.
- Firebase.
- Material UI.
- Librerías como Formik, Yup, SweetAlert2 y Sonner.
- Como crear rutas protegidas.

Un curso muy completo, que para poder aprobarlo la rubrica indicaba que debemos realiazar un proyecto que sea un Ecommerce, para poder aplicar todo lo visto hasta ahora.

Me decidí por hacer el Ecommerce de Optitech una marca personal de un servicio de reparación, mantenimiento y optimización de Equipos informáticos. Que en este caso añade venta de insumos. El proyecto consiste en una SPA, con un pequeño backend desarrollado en Firebase y que tendrá un deploy en Vercel.
